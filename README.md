# Neural Networks — from scratch & applied

Neural-network implementations built from first principles **and** applied to real datasets — demonstrating the mechanics, not just library use.

## What it does
- `Neural Networks from scratch.py` — a neural network implemented **without** a deep-learning framework (manual forward pass, backpropagation, gradient descent).
- `Classification of Hoda Dataset.ipynb` — handwritten Persian-digit (Hoda) classification.
- `Regression.py`, `LM.py` — regression and learning-method examples.
- Applied datasets: `diabetes.csv` (medical-risk prediction) and daily-temperature data.

## How it works
The from-scratch model implements the full training cycle — weighted sums, activation functions, loss, backpropagation and weight updates — so the maths behind deep learning is explicit. The applied notebooks then solve real classification and regression problems with higher-level libraries.

## Role within my work (MyOTGO)
This first-principles understanding underpins the AI models I design across **MyOTGO** — from behavioural-prediction models (device-action prediction from user behaviour) to the classification and regression components inside the platform's intelligence layer.
