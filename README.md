# Neural Networks — from scratch & applied

Neural-network implementations built from first principles and applied to real datasets.

## Contents
- `Neural Networks from scratch.py` — a neural network implemented without a deep-learning framework
- `Classification of Hoda Dataset.ipynb` — handwritten-digit (Hoda) classification
- `Regression.py`, `LM.py` — regression and learning-method examples
- `diabetes.csv`, daily-temperature data — applied datasets

Tech: Python · NumPy · scikit-learn · TensorFlow / Keras · Jupyter.
